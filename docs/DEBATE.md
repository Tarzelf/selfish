# Debate verdicts (loop 3)

Locked after the product-debate brief. Full argument stays in that brief; this is what we will not reopen without new evidence.

| Question | Verdict |
| --- | --- |
| Catalog vs live vs hybrid | Hybrid. 80% composed, 20% alive. Catalog-only is a coward’s version of the brief. Fully live is the founder’s ex. |
| One app or two | One app, two weathers, one lock. Do not call Still therapy. Do not make Want the icon. |
| Chat vs lean-back | Lean-back is the product. Interaction is a courtesy, never a job. No text box on the home screen. |
| The name | Keep **Selfish**. It is only toxic if we meter her. If launch research shows a hard flinch, Selfish stays the studio and the store name gets quieter — not preemptively. |
| Look | A dim warm room. Paper, not marble. Desire does not “go red.” |
| Aftercare | A composed fourth movement the system cannot skip. No commerce in the come-down. |
| Money | Subscription later, after a complete first night. Never sell minutes. Never sell “more intense” as a SKU. |

Taste here is a series of refusals. If the first impressive demo needs a text field, it is a demo of the wrong product.
