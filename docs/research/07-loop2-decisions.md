## Updated positioning

> **Selfish** is a private listening ritual: a voice that shapes the night around what you want — composed like good erotica, personal like a whispered aside, never a chatbot interview.

Not: Headspace. Not: Grok sexting. Not: another Quinn library.

---

## Competitive update

White space is **narrowing**. Hearr / Velvet already sell questionnaire → spoken AI story. Differentiation must be:
1. Ritual craft (arrival → aftercare), not prompt box
2. Voice intimacy QA bar
3. Taste / consent language
4. Memory of *her* preferences without sleazy companion retention
5. Honest web distribution (Bloom-style: store soft, web hot — if/when store exists)

---

## Architecture override vs tech agent

Tech agent recommended SwiftUI + RevenueCat App Store-first. **Rejected for Phase 0–1** because distribution debate and market reality require web validation first. Revisit native SwiftUI when:
- Web retention proves voice thesis
- We want a thin entitled player or Calm SKU on store

Kept from tech agent: Supabase, Grok, ElevenLabs, pre-generate+cache, safety edge function, session caps, local-first prefs.

---

## Falsification experiment (building now)

Expo web MVP:
1. Age gate
2. Mood + intensity + voice sample pick
3. Generate session (API or demo mode)
4. Listening player with stop / aftercare
5. “Felt for me?” score

**Kill if** personalization ≤ generic on felt-for-me + weak D7 return among finishers.
