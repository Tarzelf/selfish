# Selfish

Private AI listening for desire — women-first, high-fidelity voice, tasteful by design.

## Status
Research complete (loop 2). **Phase 0 web MVP scaffold** in `apps/mobile` (Expo) runs in demo mode without API keys.

## Quick start (demo)
```bash
cd apps/mobile
npm install
npm run web
```

Flow: age gate → mood/intensity/voice → listen (demo narration) → aftercare feedback.
