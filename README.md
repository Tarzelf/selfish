# Selfish

**An hour that is only yours.**

A tasteful iOS listening app. Adult, 18+. Still, for focus. Want, for desire. Written primarily for women who respond to voice the way they respond to a good erotic novel — by leaning back, not by performing in a chat.

This is not an AI girlfriend. This is not a Grok spicy-chat port. The study, the argument, and the product decisions live in [`docs/`](docs/PRODUCT.md).

## Run the room

```bash
cd mobile
npm start
# or
npm run web
```

Need headphones. The first voice is the device narrator — a stand-in for the high-fidelity TTS we will only turn on after vendor TOS review.

## Tests

```bash
cd mobile
npm test
```

The catalog cannot ship a line that smells like a minor. Every session must end in aftercare.
