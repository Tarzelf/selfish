# Cliché collocations to flag in draft scripts.
#
# WHY THIS FILE IS A LINTER AND NOT A PROMPT:
# Research on anti-slop methods (arXiv 2510.15061) found that listing banned
# phrases in the system prompt has "limited efficacy and may induce a backfire
# effect due to the pink elephant problem" — telling a model not to write
# "trembling" makes "trembling" more available to it, not less. Naive token
# banning via logit_bias is worse still: it caused "catastrophic quality
# collapse". So the list lives here, in a deterministic post-generation gate,
# and the prompt carries positive style direction instead.
#
# THE CENTRAL DIFFICULTY FOR THIS GENRE:
# The measured slop vocabulary of LLM creative writing overlaps almost entirely
# with the natural vocabulary of intimate audio — whispers, breath, shivers,
# trembling, hammering hearts. We therefore CANNOT ban the genre's own words.
# A whisper is the product. Every entry below must be a CLICHÉD COLLOCATION,
# never a bare word that a good writer would legitimately need.
#
# Format: one phrase per line, matched case-insensitively on word boundaries
# with flexible internal whitespace. Lines starting with # are comments.
